You are in for a treat today, no pun intended.

POV: You have borrowed three books and you are looking to return each book accordingly.

Through this mini project, it covers the following:
1. Uses console interface
2. Displays the list of freely available books to read
3. Provides additional information on each of those books
4. Each book has its deadline period and book reference number, which will be sued for a validation process

Once the user decides to bring the back to the library,
1. The user will be able enter thier desired book to return
2. from the additional information, they will be asked to go through verification
3. Through its validation process, one of the features include the book's reference, which will be the main feature used in the validation process as well as the deadline period.
